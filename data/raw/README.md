# Raw motion-capture recordings

The 200 de-identified recordings (`take###_P##_###_chr01.csv`, ~3 MB each) are too large for GitHub and are
archived on Zenodo: **[DOI to be added]**. Download the archive and unpack the CSV files into this folder.

File name: `take{participant number}_{participant_id}_{trial}_chr01.csv`, e.g. `take007_P07_003_chr01.csv` is
participant P07, putt 3. One file = one putt. See `../README.md` (data dictionary) for the file format.
