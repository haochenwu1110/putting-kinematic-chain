## Q2 推得快的那几杆，是谁多出了力

下杆平均握把速度的个人内方差：来自下杆幅度 108%（95% CI 97–115%），来自下杆时间 -8%（-15–3%）。
与杆头速度的个人内相关：上杆长度 r_rm = 0.46，下杆时间 -0.07，下杆平均握把速度 0.59。

上杆长度的逐杆变化来自（个人内方差归因，95% CI）：

- Pelvis：39%（23–56%）
- Trunk：22%（10–37%）
- Lead shoulder：17%（7–26%）
- Trail shoulder：15%（12–20%）
- Lead elbow/forearm：-8%（-15–0%）
- Trail elbow/forearm：14%（-3–33%）
- Residual：0%（0–1%）

击球时握把速度的逐杆变化来自：

- Pelvis：36%（22–59%）
- Trunk：17%（8–30%）

- Lead elbow/forearm：1%（-6–12%）
- Trail elbow/forearm：17%（-5–36%）
- Residual：0%（-1–2%）

与杆头速度相关（FDR q < 0.05）的关节贡献：13 个；前 5 个：

## Q3 杆面开的那几杆，是谁变了

前侧前臂击球时扭转的逐杆变化来自：Pelvis 20%（8–33%）；Trunk 10%（-5–25%）；Shoulder 32%（13–56%）；Elbow/forearm 38%（13–62%）
后侧前臂击球时扭转的逐杆变化来自：Pelvis 13%（2–27%）；Trunk 17%（7–28%）；Shoulder 30%（15–48%）；Elbow/forearm 39%（18–58%）

与杆面角相关（FDR q < 0.05）的运动链特征：3 个
- roll_trail_total_imp_deg: r_rm = 0.33 [0.19, 0.46]，q = 0.000465，稳健 = True
- roll_trail_pelvis_rot_imp_deg: r_rm = 0.26 [0.12, 0.40]，q = 0.0105，稳健 = True
- ivz_shoulder_trail: r_rm = -0.26 [-0.39, -0.11]，q = 0.011，稳健 = True

时间连续分析（聚类置换检验，p < 0.05 的聚类）：

- cr_lead_trunk：backswing 47% 至 downswing 50%，p = 0.029，平均 r = 0.18
- cr_lead_shoulder：无
- cr_lead_elbow：无
- cr_trail_trunk：backswing 0% 至 downswing 43%，p = 0.048，平均 r = 0.20
- cr_trail_shoulder：downswing 34% 至 follow-through 34%，p = 0.038，平均 r = 0.19
- cr_trail_elbow：无
