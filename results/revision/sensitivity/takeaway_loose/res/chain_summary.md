## Q2 推得快的那几杆，是谁多出了力

下杆平均握把速度的个人内方差：来自下杆幅度 105%（95% CI 96–115%），来自下杆时间 -5%（-15–4%）。
与杆头速度的个人内相关：上杆长度 r_rm = 0.45，下杆时间 -0.06，下杆平均握把速度 0.58。

上杆长度的逐杆变化来自（个人内方差归因，95% CI）：

- Pelvis：39%（24–57%）
- Trunk：22%（11–37%）
- Lead shoulder：17%（7–26%）
- Trail shoulder：16%（12–21%）
- Lead elbow/forearm：-8%（-15–0%）
- Trail elbow/forearm：13%（-3–31%）
- Residual：-0%（-0–1%）

击球时握把速度的逐杆变化来自：

- Pelvis：36%（23–60%）
- Trunk：16%（7–30%）
- Lead shoulder：15%（4–23%）
- Trail shoulder：13%（3–23%）
- Lead elbow/forearm：1%（-6–11%）
- Trail elbow/forearm：18%（-5–36%）
- Residual：1%（-1–3%）

与杆头速度相关（FDR q < 0.05）的关节贡献：14 个；前 5 个：
- iv_pelvis_rot: r_rm = 0.37 [0.24, 0.50]，q = 4.63e-06，稳健 = True
- bs_shoulder_trail_mm: r_rm = 0.37 [0.24, 0.50]，q = 4.63e-06，稳健 = True

## Q3 杆面开的那几杆，是谁变了

前侧前臂击球时扭转的逐杆变化来自：Pelvis 22%（8–39%）；Trunk 10%（-7–26%）；Shoulder 33%（12–59%）；Elbow/forearm 36%（6–62%）
后侧前臂击球时扭转的逐杆变化来自：Pelvis 10%（-0–24%）；Trunk 19%（9–30%）；Shoulder 27%（14–44%）；Elbow/forearm 43%（19–62%）

与杆面角相关（FDR q < 0.05）的运动链特征：4 个
- roll_trail_total_imp_deg: r_rm = 0.34 [0.20, 0.47]，q = 0.000238，稳健 = True
- roll_trail_pelvis_rot_imp_deg: r_rm = 0.27 [0.12, 0.40]，q = 0.00904，稳健 = True
- ivz_shoulder_trail: r_rm = -0.25 [-0.39, -0.11]，q = 0.0126，稳健 = True
- roll_trail_shoulder_imp_deg: r_rm = 0.24 [0.09, 0.37]，q = 0.0217，稳健 = True

时间连续分析（聚类置换检验，p < 0.05 的聚类）：

- cr_lead_trunk：backswing 35% 至 downswing 47%，p = 0.020，平均 r = 0.18
- cr_lead_shoulder：无
- cr_lead_elbow：无
- cr_trail_trunk：无

- cr_trail_elbow：无
