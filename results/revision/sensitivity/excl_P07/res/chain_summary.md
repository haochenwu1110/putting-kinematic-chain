## Q2 推得快的那几杆，是谁多出了力

下杆平均握把速度的个人内方差：来自下杆幅度 105%（95% CI 97–116%），来自下杆时间 -5%（-16–3%）。
与杆头速度的个人内相关：上杆长度 r_rm = 0.46，下杆时间 -0.04，下杆平均握把速度 0.58。

- Trail shoulder：17%（11–22%）

## Q3 杆面开的那几杆，是谁变了

前侧前臂击球时扭转的逐杆变化来自：Pelvis 21%（8–35%）；Trunk 10%（-5–25%）；Shoulder 28%（8–54%）；Elbow/forearm 42%（13–68%）
后侧前臂击球时扭转的逐杆变化来自：Pelvis 14%（1–29%）；Trunk 18%（7–30%）；Shoulder 27%（12–45%）；Elbow/forearm 42%（18–61%）

与杆面角相关（FDR q < 0.05）的运动链特征：3 个
- roll_trail_total_imp_deg: r_rm = 0.33 [0.19, 0.46]，q = 0.000744，稳健 = True
- roll_trail_pelvis_rot_imp_deg: r_rm = 0.27 [0.12, 0.41]，q = 0.0103，稳健 = True
- ivz_shoulder_trail: r_rm = -0.26 [-0.40, -0.11]，q = 0.0116，稳健 = True

时间连续分析（聚类置换检验，p < 0.05 的聚类）：

- cr_lead_trunk：backswing 49% 至 downswing 40%，p = 0.039，平均 r = 0.18
- cr_lead_shoulder：无
