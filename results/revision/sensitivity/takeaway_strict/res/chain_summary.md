## Q2 推得快的那几杆，是谁多出了力

下杆平均握把速度的个人内方差：来自下杆幅度 104%（95% CI 95–115%），来自下杆时间 -4%（-15–5%）。
与杆头速度的个人内相关：上杆长度 r_rm = 0.46，下杆时间 -0.06，下杆平均握把速度 0.58。

上杆长度的逐杆变化来自（个人内方差归因，95% CI）：

- Pelvis：39%（22–58%）
- Trunk：22%（10–37%）
- Lead shoulder：17%（7–27%）
- Trail shoulder：17%（12–21%）
- Lead elbow/forearm：-8%（-15–0%）
- Trail elbow/forearm：13%（-3–31%）
- Residual：-0%（-1–1%）

击球时握把速度的逐杆变化来自：

- Pelvis：36%（22–60%）
- Trunk：17%（8–31%）
- Lead shoulder：16%（4–23%）
- Trail shoulder：13%（4–23%）
- Lead elbow/forearm：1%（-6–11%）
- Trail elbow/forearm：17%（-5–36%）
- Residual：1%（-1–3%）

与杆头速度相关（FDR q < 0.05）的关节贡献：14 个；前 5 个：
- bs_shoulder_lead_mm: r_rm = 0.38 [0.24, 0.50]，q = 4.17e-06，稳健 = True
- iv_pelvis_rot: r_rm = 0.38 [0.24, 0.50]，q = 4.17e-06，稳健 = True

- bs_elbow_lead_mm: r_rm = -0.35 [-0.47, -0.21]，q = 1.44e-05，稳健 = True

## Q3 杆面开的那几杆，是谁变了

前侧前臂击球时扭转的逐杆变化来自：Pelvis 20%（8–34%）；Trunk 8%（-7–24%）；Shoulder 30%（11–52%）；Elbow/forearm 41%（15–66%）
后侧前臂击球时扭转的逐杆变化来自：Pelvis 12%（1–24%）；Trunk 16%（6–26%）；Shoulder 26%（14–41%）；Elbow/forearm 46%（25–63%）

与杆面角相关（FDR q < 0.05）的运动链特征：4 个
- roll_trail_total_imp_deg: r_rm = 0.31 [0.17, 0.44]，q = 0.00153，稳健 = True
- roll_trail_pelvis_rot_imp_deg: r_rm = 0.27 [0.12, 0.40]，q = 0.00923，稳健 = True
- ivz_shoulder_trail: r_rm = -0.26 [-0.39, -0.11]，q = 0.0119，稳健 = True
- roll_trail_shoulder_imp_deg: r_rm = 0.22 [0.07, 0.36]，q = 0.0423，稳健 = True

时间连续分析（聚类置换检验，p < 0.05 的聚类）：

- cr_lead_trunk：backswing 43% 至 downswing 52%，p = 0.016，平均 r = 0.18
- cr_lead_shoulder：无
- cr_lead_elbow：无
- cr_trail_trunk：无
- cr_trail_shoulder：downswing 34% 至 follow-through 35%，p = 0.029，平均 r = 0.20
- cr_trail_elbow：无
